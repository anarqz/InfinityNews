- Navegue pelo launcher com um controle XInput ou Steam Input.
- Abra o teclado virtual do Steam no Modo Jogo ao digitar.
- Mantenha a sessão conectada no Windows com armazenamento local criptografado; o launcher informa quando está verificando uma sessão salva.
- Renderização por software para compatibilidade com Wine/Proton.
- Instalador interativo para Debian e SteamOS, descrito no [guia de instalação](https://github.com/anarqz/InfinityHorizon/tree/v1.0.6#install-on-linux-and-steam-deck).
- Os metadados distribuídos não incluem mais caminhos locais de compilação do overlay.

Baixe o ZIP Windows x64 abaixo, extraia em uma pasta própria e execute `infinity.exe`. Instalações existentes podem usar o atualizador do launcher. Linux e Steam Deck usam o mesmo build pelo Proton.

[Download e notas completas](https://github.com/anarqz/InfinityHorizon/releases/tag/v1.0.6)
