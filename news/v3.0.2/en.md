- **Car pack sets.** A mod set such as the ZephyrSkies FM5 or FM6 Addon Packs now shows as one card on the Mods page. Choose the folder that holds the set's ZIP files and **Install all** installs every pack, its Common first, and reports each pack. The two Commons always load first in ExtraOptions' load order.
- **ExtraOptions mods only.** The launcher now installs only ExtraOptions mods. Mods installed in an older format are marked "No longer supported": you can still disable and remove them (the original game files are restored), but not enable or update them. While one that changes gameplay is enabled, online play is refused until you disable or remove it.
- The Remix Car Pack is no longer in the catalog.

The hook is unchanged (0.3.0+fh2online.124). Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v2.0.4#install-on-linux-and-steam-deck).
