- **One set of profiles, offline and online.** Up to three profiles, signed in or not; every one plays both offline and online. A profile you create without signing in (Noob) registers its name the next time you sign in; if someone took it meanwhile, the launcher asks for a new one and the profile and its save stay as they are.
- **Saves.** A Noob profile uses one save folder offline and online. A Hardcore profile online always continues from your cloud career; played offline, it keeps that progress in a separate local folder that never uploads.
- **Plain names.** Gamertags no longer carry a `#number`. If your name was changed because two players had the same one, the launcher tells you and lets you choose another name once, for free.
- **Privacy.** At sign-in the launcher sends an anonymous ID of this PC (a hash, never the raw value) to the account service, to recognise the same device. See About.
- Infinity hook 0.3.0+fh2online.87.

Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v1.0.13#install-on-linux-and-steam-deck).
