Infinity Horizon 1.0.2

### Download
Download **infinity-horizon-1.0.2-windows-x64.zip**, extract the entire archive into its own folder outside the Azimuth installation, and run **infinity.exe**. Keep the bundled files and signature sidecars together.

The package includes the Windows x64 launcher, updater, Infinity hook, overlay, English/Portuguese translations, and license notices. Game and Azimuth files are not included.

### Changes
- Fix Extra Options installation by following GitHub release-download redirects.
- Verify the archive and supported files before installing beside azimuth.exe.
- Show clear English and Portuguese messages for download, folder-access, and antivirus failures.

The JSON descriptor and its detached signature are provided for authenticated automatic updates.
