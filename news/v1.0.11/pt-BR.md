- **Um novo catálogo oficial de mods.** Ele lista o runtime de mods do Infinity, o Extra Options, o Nitro System e o Remix Car Pack, já revisado. Cada download é conferido com o tamanho e o hash listados no catálogo.
- **Nenhum mod é obrigatório.** O Extra Options não é mais exigido para jogar, online ou offline. Um mod ainda traz o que precisa: o Nitro System instala o Extra Options.
- **O runtime de mods se instala sozinho.** Ele vem do catálogo quando você instala um mod que precisa dele, e o launcher confere as duas assinaturas antes. Ele não vem mais dentro do launcher.
- **Mods feitos com os seus arquivos.** O Remix Car Pack usa o pacote de carros que você já tem: escolha a pasta dele, uma pasta acima ou o ZIP. O launcher encontra os arquivos, confere cada um e guarda a própria cópia verificada, então o pacote pode mudar de lugar depois. No Steam Deck, um navegador de arquivos embutido funciona com o controle e o teclado do Steam.
- **Toda instalação mostra uma prévia antes.** Você vê onde o mod vai ficar e quais arquivos existentes ele substitui. Os arquivos substituídos ficam guardados e voltam quando você desativa ou desinstala o mod. Atualizações mostram a mesma prévia.
- **Outros catálogos.** Configurar → Catálogo de mods aceita o endereço de outro catálogo. Um catálogo não oficial sempre aparece como tal e nunca substitui o runtime de mods instalado.
- **Limites do GitHub.** Quando o limite da API do GitHub é atingido, as atualizações do launcher passam a ser lidas pela página de releases. A confiança é a mesma de antes: o descritor assinado é verificado, e o pacote precisa bater com o hash dele.
- **Telas offline.** O aviso "Verificando a última versão oficial…" não aparece antes de você entrar.
- **Correções:**
  - a tela de progresso dos mods aparece certa no Linux e no Steam Deck;
  - textos no singular ("1 arquivo");
  - um botão cortado em português;
  - as mensagens de erro citam o endereço certo.
- O log do launcher agora registra como o launcher foi fechado.

No Windows, use o atualizador do launcher ou extraia o ZIP Windows x64 em uma pasta própria. No Linux/Steam Deck, o atualizador do launcher aplica esta versão; se não conseguir, execute novamente o [instalador para Linux/Steam Deck](https://github.com/anarqz/InfinityHorizon/tree/v1.0.11#install-on-linux-and-steam-deck).
