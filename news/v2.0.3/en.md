- **Infected alone.** An Infected event with only one player ends when the race starts, never during the countdown.
- **Update diagnostics.** The launcher's log now says whether an update is required or you are current, and why, which helps support when an update isn't offered.
- **Smaller fixes** to the world server's logs.

The hook is unchanged (0.3.0+fh2online.118). Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v2.0.3#install-on-linux-and-steam-deck).
