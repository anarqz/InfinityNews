- **Azimuth 1.0.3 with ExtraOptions built in.** The Infinity hook (0.3.0+fh2online.96) is now ExtraOptions 0.3.9 with Infinity's online services. Install or reinstall it on Configure; ExtraOptions is part of Infinity and is configured on the Mods page.
- **One server: play.infinity-horizon.com.** The launcher connects to play.infinity-horizon.com, which is the only server in the server list now.
- **Mods load through ExtraOptions.** Catalog mods (Nitro System, Remix Car Pack) install as ExtraOptions mods. Mods you copied into Azimuth's `mods` folder yourself show as "Installed manually": enable, disable or delete them there. Uninstalling a mod leaves nothing of it behind.
- **Modded lobbies list the mods your game actually loaded.** When you open or join a lobby, Infinity sends the mods ExtraOptions loaded in this game, including the ones you installed yourself; only players with the identical files can join.
- **New Noob profile from a Hardcore career.** When you create a Noob profile you can start it from one of your Hardcore careers on this PC (a copy; the Hardcore profile keeps its own save).
- **Fixes:** a crash at start on some Windows PCs (Direct3D device removed) caused by the in-game overlay; every folder and file is now chosen in the launcher's own picker, on Windows and Linux/Steam Deck.

Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v1.1.0#install-on-linux-and-steam-deck).
