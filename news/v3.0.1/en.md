- **Car meets work again.** Joining a car meet could fail every time on 3.0.0: the launcher gave up before the game finished connecting. Car meets now get more time to connect.

The hook is unchanged (0.3.0+fh2online.124). Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v2.0.4#install-on-linux-and-steam-deck).
