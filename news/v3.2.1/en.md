- **The Mods page no longer freezes the launcher.** Opening a mod's list of replaced files could hang the launcher, make it use more and more memory, and keep it running in the background after you closed its window. The launcher now stays responsive, and it always closes fully when you close it.
- **Clearer file previews.** When the launcher cannot read which files a mod would replace, it now says why.

Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v2.0.4#install-on-linux-and-steam-deck).
