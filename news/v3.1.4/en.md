- **AZIMUTH profile.** Your Azimuth profile now plays Azimuth's own save on this PC, online and offline; it has no cloud save. Your old Noob cloud save can be copied into it or exported to a file from the AZIMUTH row.
- **Former Noob players:** the first time you sign in after this update, a popup shows your old Noob save and your current Azimuth save for each game where they differ (level, credits, date). Copy my Noob save backs up your Azimuth save first; Keep Azimuth's save changes nothing; Not now asks again next time.
- **Cleaner PLAY screen:** messages now sit on one notice line, and every choice that copies, restores or replaces a save (including keeping the cloud or this PC's HARDCORE save) opens a popup that says what is replaced and where the backup goes.
- **Use another save on this PC…** On the AZIMUTH row, pick any save this PC has (a HARDCORE profile, an old Noob save or a launcher backup), with its level, credits and date; your current Azimuth save is backed up first.
- **Crash screen:** it shows a crash once, with Get logs and Ignore. Get logs (and "Found a bug?" → Get launcher logs) puts one zip on your Desktop and opens #help on Discord.
- The game files are updated the next time you press PLAY.

Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v2.0.4#install-on-linux-and-steam-deck).
