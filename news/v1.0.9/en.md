- Mods now play online. Players with mods that affect multiplayer meet in modded lobbies with exactly the same mods. Hardcore profiles play without multiplayer mods (Extra Options still works there).
- Modded sessions don't post leaderboard results, scores or Drivatars.
- The lobby list can show modded lobbies, marks a lobby whose mods differ from yours, and shows each player's mods in their details.
- Custom mods: put a mod's folder in `%LOCALAPPDATA%\ForzaInfinity\launcher\mods\custom\` and it appears in Mods as "Custom · unofficial". You confirm each one before it installs. Car packs can bring their own cars, including the game database changes they need. Only one car pack can be active at a time. Custom mods that run their own code are not supported yet.
- Extra Options 0.2.98 is now required to play, with media overrides on. Play shows what's missing and lets you install or enable it.
- Mods work on Linux and Steam Deck.
- If your mods fail to start, the launcher says why and the game closes instead of freezing. This is no longer shown as a crash.
- Game file verification now runs only for Supporter Hardcore profiles, in the background. Closing the game no longer asks you to configure it or verify the files again.
- Holding LB + RB for 1 second now also opens and closes the overlay.
- Administrators can host dedicated lobbies.
- Mods need the Infinity hook 0.3.0+fh2online.85; the launcher offers the update.

Windows installations can use the launcher updater or extract the Windows x64 ZIP into a separate launcher folder. On Linux/Steam Deck, the launcher updater applies this release; if it cannot, rerun the [Linux/Steam Deck installer](https://github.com/anarqz/InfinityHorizon/tree/v1.0.9#install-on-linux-and-steam-deck).
